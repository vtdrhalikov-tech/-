# МастерПро

Курсовой проект Халикова Д. Р. Веб-приложение для автомастерской.

## Запуск

Скопируйте каталог masterpro в C:/xampp/htdocs, включите Apache в XAMPP и откройте http://localhost/masterpro/ . На рабочем компьютере: http://localhost/masterpro_khalikov/ . Файлы index.html, style.css и app.js должны оставаться рядом.

## Возможности

- Обзор и реестр заказ-нарядов.
- Справочники клиентов, услуг и мастеров: добавление, изменение, удаление, поиск.
- Общая административная панель с выбором четырёх таблиц.
- Защита связанных записей от удаления; обязательное назначение мастера для работы и завершения.
- Десять отчётов: незавершённые и завершённые заказы, выручка по дням, популярность услуг, работа мастеров, история клиентов, заказы без мастера, отменённые заказы, текущая загрузка, план обслуживания.
- Фильтр отчётов по плановой дате и выгрузка CSV (UTF-8, разделитель — точка с запятой).
- Печатная форма заказ-наряда с сохранением PDF средствами браузера.
- Экспорт и восстановление JSON-копии.

Данные сохраняются в localStorage по ключу masterpro-course-v1 и доступны в том же браузере по тому же адресу. Изменения сайта сохраняют этот ключ. Суммы вычисляются по текущим ценам услуг; историческая цена заказа не фиксируется. Вход, серверная проверка прав и совместная работа не реализованы. Импортируйте копии, созданные приложением: проверка произвольных JSON ограничена.

## Отдельная учебная SQL-модель

Файл database/autoservice.sql сохраняет исходную модель clients, cars, orders, parts. Она описана в теоретическом разделе курсовой и не синхронизируется с интерфейсом. Для изучения можно импортировать её в новую пустую базу utf8mb4 через phpMyAdmin. Не импортируйте поверх существующих таблиц. MySQL не требуется для браузерных операций приложения.

## Проверка

Проведена 31 дополнительная проверка административных операций, десяти отчётов, дат, CSV, печатной формы, связей, сохранения и JSON. Все тестовые записи созданы в отдельном браузерном профиле. Демонстрационные данные предназначены для учебной работы.

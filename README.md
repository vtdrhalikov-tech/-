# МастерПро

Курсовой проект Халикова Д. Р. по теме «Разработка веб-приложения для автомастерской».

## Состав

- `masterpro/index.html` — разметка интерфейса.
- `masterpro/style.css` — стили и адаптивность.
- `masterpro/app.js` — CRUD, поиск, фильтрация, проверка данных и резервное копирование.
- `database/autoservice.sql` — отдельная учебная реляционная база данных.

## Запуск сайта в XAMPP

Скопируйте каталог `masterpro` в `C:/xampp/htdocs`, включите Apache и откройте http://localhost/masterpro/ . Также интерфейс можно открыть напрямую из `index.html`, но для постоянной работы рекомендуется использовать один и тот же HTTP-адрес.

Данные сайта сохраняются в localStorage браузера по ключу `masterpro-course-v1`. Они не отправляются в MySQL. Серверной авторизации и совместной работы нескольких пользователей в этой версии нет.

## База данных

В phpMyAdmin создайте пустую базу `autoservice` с кодировкой utf8mb4 и импортируйте `database/autoservice.sql`. Если база с таким именем уже существует, используйте другое имя и не импортируйте файл поверх существующих таблиц.

SQL содержит таблицы `clients`, `cars`, `orders`, `parts` и демонстрационные записи. Эта модель исследуется отдельно от браузерного интерфейса. Автоматической синхронизации между localStorage и MariaDB нет.

## Возможности

Обзор заказов, справочники клиентов, услуг и мастеров, создание и редактирование заказов, поиск и фильтрация, контроль связей при удалении, экспорт и восстановление JSON. Для статусов «В работе» и «Готово» требуется назначенный мастер.

## Резервное копирование

Кнопка «Резервная копия» выгружает JSON, «Восстановить» загружает его обратно с подтверждением замены. SQL-экспорт выполняется отдельно в phpMyAdmin. JSON и SQL не взаимозаменяемы.

Все данные в репозитории предназначены для учебной демонстрации.
